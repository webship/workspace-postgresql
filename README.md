# @webship.co/workspace-postgresql

PostgreSQL for the Webship Workspace: the DATABASE menu of a project whose database is PostgreSQL (a console in a screen, export and import, tables and sizes, a web admin), on DDEV and on the other container runtimes. An engine of [`@webship.co/workspace-database`](https://github.com/webship/workspace-database).

The first version is on its way: see the issues of this repository.

Part of the [Webship Workspace](https://github.com/webship/workspace), the container-based development workspace (DDEV by default).
